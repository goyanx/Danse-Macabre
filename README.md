# The Glass House

An AI-assisted chamber mystery built on the original Ren'Py/Python architecture of Danse Macabre.

The story follows a late-night visit to Lila and Malcolm Vale, a married couple whose polished townhouse performance gradually exposes an invented daughter, Vivian. The structure is inspired by interactive social-drama games and domestic stage conflict, with original characters, locations, beats, art, and sound.

## Runtime

- Ren'Py project with Python packages under `game/python-packages`.
- Local Ollama powers the Director and dynamic NPC replies when available.
- Deterministic fallback lines keep the game playable when Ollama is offline.
- Character voice can use cached OpenAI TTS, ElevenLabs, local Kokoro, system voice fallback, or be disabled from Preferences.
- ElevenLabs can provide optional character speech and generated sound effects under `game/audio/sfx`.

## Ollama

The local model adapter reads:

- `OLLAMA_BASE_URL`, defaulting to `http://localhost:11434`
- `OLLAMA_MODEL`, defaulting to `qwen3:8b`
- `OLLAMA_NUM_PREDICT`, defaulting to `256`

## Story Structure

The Acts and progression beats are documented in `docs/the_glass_house_story_outline.md`.

AI agents and authors should begin with `docs/ai_story_authoring_guide.md`. It documents the project architecture, narrative data contracts, dialogue rules, asset system, spoiler boundaries, async performance requirements, and the complete workflow for creating another story.

Each beat has:

- a location
- dialogue/action trigger phrases
- a callback label
- a journal entry
- a fallback Director nudge

The Director watches for repeated non-progress turns and offers a subtle nudge toward the current beat. Players can also press the in-game Director button for help.

## Assets

High-fidelity room backgrounds were generated with the built-in GPT image generation flow and are documented in `docs/gpt_imagegen_assets.md`.

Externally sourced optional assets and credits are documented in `docs/external_assets.md`.

Project-bound deterministic placeholder and menu assets can be regenerated by:

```powershell
python tools\generate_facade_assets.py
```

Sound effects are generated with ElevenLabs using `ELEVENLABS_API_KEY` or `XI_API_KEY`:

```powershell
python tools\generate_elevenlabs_sfx.py
```

Voice provider setup is documented in `docs/tts_providers.md`.

## Tests

Install the small development dependency set, then run the offline regression suite:

```powershell
python -m pip install -r requirements-dev.txt
python tools\run_tests.py
```

Run the same suite followed by Ren'Py lint:

```powershell
python tools\run_tests.py --lint
```

Boot Ren'Py, play the deterministic spoken fixture through the production voice
path, and then run lint:

```powershell
python tools\run_tests.py --voice-init --lint
```

The tests do not call cloud APIs, Ollama, or Kokoro. The engine test verifies
voice initialization, decoding, mixer state, and sustained playback without
depending on provider availability. It also performs a real save while
unpickleable TTS runtime state is active. GitHub Actions runs both the offline
suite and engine voice test on every push and pull request.
